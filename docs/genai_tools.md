# MSDS 431 Assignment 10 — GenAI Tools

## Tool

**OpenAI ChatGPT**

## How the Tool Was Used

ChatGPT was used as a development assistant during the implementation and testing of the movie database application.

Areas of assistance included:

- **Python and DuckDB:** Assistance with designing the database schema, loading CSV datasets using Polars, inserting records into DuckDB, and validating data integrity.
- **Go development:** Assistance with implementing the command-line application, connecting Go to DuckDB, writing SQL queries, and organizing application functionality across source files.
- **Application features:** Guidance on implementing movie searches, genre exploration, actor searches, ranked movie listings, genre analysis, movie details, and personal collection management.
- **Testing:** Assistance with developing unit and workflow tests, testing database constraints, troubleshooting test failures, and interpreting Go test coverage.
- **Benchmarking:** Assistance with creating Go benchmarks and interpreting execution time, memory allocation, and allocation counts.
- **Troubleshooting:** Assistance with resolving compiler, CGO, GCC, DuckDB driver, and Windows environment configuration issues.
- **Documentation:** Assistance with project organization, setup instructions, README content, and reporting implementation and performance results.

## Student Responsibility

The student was responsible for directing the development process, reviewing suggested implementations, executing commands, integrating code, and evaluating the application.

The student independently ran the data-ingestion and validation scripts, tested application functionality, executed Go tests and benchmarks, reviewed the results, and verified that the application and personal collection functionality worked as expected.

AI-generated suggestions were treated as assistance rather than authoritative results. Code, database operations, test results, and performance measurements were reviewed and verified before inclusion in the assignment.
